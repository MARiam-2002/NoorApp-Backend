# Debug Session: signup-500-internal-error

- **Status**: [OPEN]
- **Session ID**: signup-500-internal-error
- **Created**: 2026-08-07
- **Symptom**: When Flutter client calls POST /auth/sign-up (register), they receive HTTP 500 Internal Server Error.
- **Expected**: Should return 201 Created with { user, tokens } AuthResult, or 400/409 with a proper error envelope.
